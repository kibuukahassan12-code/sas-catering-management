Import Instructions

⚠️ Important:

For Excel files (.xlsx, .xls), the openpyxl library must be installed.

If you encounter an error, install it by running: pip install openpyxl

Client Selection:

  • Select a Client to attach all client details (name, phone, email, company) to the budget
  • If you select a client but no event, a new event will be automatically created with the client's information
  • If you select both client and event, the event will be updated with the client's details
  • The imported budget will appear in the budgets section and can be edited

File Format Requirements:

CSV/Excel files should have the following columns:

  • Category - Budget category (Food Items, Sauces, Market Accessories, etc.)
  • Description - Item description (required)
  • Quantity - Quantity (default: 1)
  • Unit Cost or Cost - Unit cost in UGX (default: 0)
  • Notes - Optional notes

Note: The first row should contain column headers. Category names should match budget categories exactly. Column names are case-insensitive.
